# Iteration 3 UI refinement — v2.4.1

- Added a direct Light/Dark toggle on the sign-in screen, onboarding header, and workspace top bar.
- Theme changes apply immediately and are saved in the browser.
- For signed-in users, the preference is also saved to their account.
- Removed the System option from the visible Settings interface.
- New accounts default to Light mode; legacy System preferences are resolved once to the current device theme.
